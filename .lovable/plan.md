## خطة بناء نظام إدارة المحتوى (CMS) للأدمن

### 1. قاعدة البيانات (Supabase)
إنشاء الجداول التالية مع RLS:
- **`cities`** — (id, name_ar, name_en, slug, sort_order, active)
- **`categories`** — التصنيفات الرئيسية (id, name_ar, name_en, slug, icon, sort_order, active)
- **`subcategories`** — التصنيفات الفرعية (id, category_id, name_ar, name_en, slug, sort_order, active)
- **`providers`** — مقدمو الخدمة (id, subcategory_id, city_id, name, description, price_from, price_to, whatsapp, instagram, address, rating, is_featured, featured_until, sort_order, active, created_at)
- **`provider_images`** — صور المقدمين (id, provider_id, image_url, sort_order)
- **`storage bucket: provider-images`** — رفع الصور (عام للقراءة، الكتابة للأدمن فقط)

سياسات RLS:
- الجميع: قراءة الصفوف `active = true`
- الأدمن فقط: إنشاء/تعديل/حذف (عبر `has_role(auth.uid(), 'admin')`)

### 2. لوحة الأدمن — `/admin`
استبدال صفحة الأدمن الحالية بقائمة جانبية (Sidebar) فيها:
- **الإحصائيات** (الموجودة حالياً)
- **المستخدمون** (الموجود حالياً)
- **الإعدادات** ← قسم منسدل يحوي:
  - **المدن** — جدول CRUD
  - **التصنيفات** — جدول CRUD
  - **التصنيفات الفرعية** — جدول CRUD مع اختيار التصنيف الأب
  - **مقدمو الخدمة** — جدول CRUD كامل + رفع صور + خيار "مميز" (featured) + ترتيب الأولوية

كل صفحة فيها:
- جدول بالبيانات
- زر "إضافة جديد" يفتح نموذج (Dialog)
- أزرار تعديل/حذف لكل صف
- خاص بمقدمي الخدمة: رفع صور متعددة + سحب لإعادة الترتيب + تبديل "مميز" مع تاريخ انتهاء الترقية

### 3. الواجهة العامة (`public/app.html`)
تحديث الموقع ليقرأ البيانات من Supabase بدلاً من البيانات الثابتة:
- جلب المدن ديناميكياً
- جلب التصنيفات والفرعية ديناميكياً
- جلب مقدمي الخدمة حسب المدينة/التصنيف
- ترتيب: المميزون أولاً (`is_featured = true` و `featured_until > now()`) ثم حسب `sort_order`
- زر واتساب يستخدم رقم المقدم مباشرة
- معرض صور لكل مقدم خدمة

### 4. تغييرات أخرى مطلوبة
- تغيير اسم العلامة من **AZHLIHA** إلى **EZHLIHA** في جميع الملفات (admin، login، signup، app.html)
- إضافة المدن الافتراضية في seed: الرياض، جدة، مكة المكرمة، الدمام، الطائف

### 5. التفاصيل التقنية
- نموذج الإضافة/التعديل: مكتبة `react-hook-form` + `zod` للتحقق
- رفع الصور: `supabase.storage.from('provider-images').upload(...)` من واجهة الأدمن (يتطلب أن يكون المستخدم أدمن — RLS على الـ bucket)
- خيار "ترقية مميزة" — حقل `is_featured` boolean + `featured_until` (تاريخ اختياري لانتهاء الترقية)
- الترتيب اليدوي: حقل `sort_order` integer + أزرار سهم لأعلى/أسفل
- جميع عمليات CRUD تستخدم Supabase client مباشرة من المتصفح (RLS تحمي البيانات)

### 6. خطة التنفيذ بالترتيب
1. Migration: إنشاء كل الجداول + RLS + bucket + إدخال بيانات افتراضية (المدن + تصنيف "صوالين" كمثال)
2. ترقية المستخدم الحالي إلى أدمن (لو موجود)
3. تحديث `admin.tsx` لقائمة جانبية + إنشاء صفحات الإعدادات الفرعية
4. تحديث `app.html` لقراءة البيانات الديناميكية + ترتيب المميزين أولاً
5. تغيير AZHLIHA → EZHLIHA في كل الملفات

### ملاحظات
- لن نضيف نظام دفع فعلي الآن — خانة "مميز" يدوية يفعّلها الأدمن بعد استلام الدفع خارج النظام
- الصور تُحفظ في bucket عام (للعرض السريع)؛ الكتابة محمية بـ RLS
